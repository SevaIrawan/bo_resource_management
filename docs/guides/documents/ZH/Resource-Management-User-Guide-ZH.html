1. 概述

1.1 本应用做什么？

资源管理帮助团队完成以下工作：

能力 说明
多账号登记 按品牌（如 SBMY）登记多个 WhatsApp 与 Telegram 账号
会话健康 检查账号在手机/本机是否仍在线（会话）
群组对齐 对比设备上的群与品牌标准群清单（主表）
抓取 从设备完整读取群组并写入数据库
问题 在账号页查看缺口（多余群 / 缺群 / 非管理员、重复）— 内存计算
Job Queue 自动化入群、建群、设管理员、退出/删除、设头像
导出 将筛选结果导出为 Excel，供现场作业使用

1.2 两种「登录」

请勿混淆 — 用途完全不同。

类型 用途 操作方式
仪表板登录 进入应用 用户名 + 密码（由 IT 提供，对应 users 表）
平台登录 将 WA/TG 关联到营销账号 点击 同步 (↻) → 二维码或手机号登录弹窗

仪表板密码不是 Telegram 或 WhatsApp 的密码。

1.3 什么**不会**生成问题？

会话列中的登录/登出变化不会产生问题。问题仅针对相对品牌标准的群组与管理员差异。

4.5 **同步 (↻)** 流程 — 必读

行为取决于 会话 列取值。

会话 = **已登出**

步骤 说明
1 点击 ↻
2 打开平台登录弹窗（默认二维码，或手机号登录）
3 在营销手机上扫码（WA：已关联的设备；TG：链接桌面设备）
4 成功后：会话 在线；可能提示 Scrape now / Later

会话 = **在线**

步骤 说明
1 点击 ↻
2 App 检查 WA/TG 在本机仍活跃
3 若 OK：可提示 Scrape now / Later
4 若失败：要求重新登录

说明：

  • 平台登录仅在桌面应用内运行（非仅浏览器）。
  • 二维码约 10 秒未出现：关闭弹窗，稍等，再 同步。

4.6 最后更新列（完整抓取）

条件 显示 操作
会话已登出 请先点击同步 (↻) 登录 先同步
待机 最后更新 时间戳 需时 同步 → Scrape now
进行中 进度 + Cancel scrape（备注列） 等待

Later = 会话保持在线，不完整抓取。

5. 账号页问题 — 类型与修复

5.1 问题显示在哪里？

无「工单」标签、无「处理工单」弹窗，也无 ticket_issue_handles /「进行中」工作流。

账号完成抓取/同步后，应用在内存中比对设备群（每日快照）与品牌主表。缺口显示在 账号 页的 未对齐 状态以及 Junk / 缺群 / 非管理员 计数。

5.2 问题类型（仅五种）

类型（内部） 界面含义 常见修复
daily_junk_group Junk — 设备有、主表无 Operations → Leave / 退出（Job Queue SETUP）
missing_group 缺群 / 缺标准群 — 主表有、本账号无 Operations → Join missing（SETUP）
not_admin 非管理员 — 已入群但非 Admin Operations → Set admin（SETUP）
duplicate_group_id 相同群 ID、名称冲突 核对主表数据（IT）
duplicate_group_name 同名不同 ID 核对主表数据（IT）

没有 group_count_mismatch（群数不一致 / 聚合 Y≠X）类型。会话登录/登出不会生成问题。

5.3 如何修复

步骤 操作
1 在账号页查看 未对齐 行及 Junk / 缺群 / 非管理员计数
2 打开 Operations → Job Queue → 品牌 → 按需 SETUP（Join / Set admin / Exit）
3 任务完成后：对该账号 同步 → 抓取，刷新 daily
4 数据对齐后徽章减少（数据库更新后实时反映）

手机或自动化已修复但仍有缺口：再次 同步 → 抓取，使最新设备数据进入数据库。

6. 群组矩阵 — 入群/管理员（账号页卡片）

Reporting 标签壳层已移除。入群/管理员矩阵从账号页品牌卡片 群数量徽章 打开 — 只读。

控件 用途
入口 账号 → 品牌卡片标题栏 → WA/TG Group 徽章
Full Group / Full Admin 相对主表的入群或管理员 Yes/No（该品牌+平台下全部账号）
搜索 / Status 按名称 / 库存状态筛选
列筛选 账号列头 Yes / No / All

抓取或 Supabase 变更后自动刷新。无需独立 Reporting 页面即可看到最新矩阵。

7. Operations — Job Queue

Operations 仅为 Job Queue — 无 Overview 标签。库存摘要在账号页品牌标题栏 chips（§4.2）。

区域 功能
品牌卡片 展开品牌 → 按动作类型显示队列表
Join missing 使用品牌主表邀请链接入队入群
Create group 在设备上建群并导出邀请链接
Set admin 由 OWNER/ADMIN 账号提升目标账号
Exit / delete 退出多余群（删除需在 设置 → Worker 中启用）
Set photo 品牌群头像任务（Telegram）
SETUP 弹窗 选择账号/群后入队 — 使用真实设备/主表数据

该账号会话须为 在线 才能打开 Job Queue SETUP。延迟与退出/删除开关在 设置（§8）中配置。

8.3 偏好设置 — 账号自动抓取

取代旧版「账号自动同步」+「间隔（分钟）」。

控件 功能
On Scheduled 默认 开 — 每天在设定本地时刻运行一次（应用需已打开）
每日运行时刻 默认 12:00 PM（本地）
Scrape Now 默认 关 — 一次性自动抓取；打开时品牌勾选全部未选；状态显示 standby，直至 Execute
品牌清单 每平台最多 6 个品牌（WA 与 TG 分开）
默认品牌（Scheduled） FWSG、JMMY、M24SG、SBMY、STMY、WBSG
模式 主按钮
On Scheduled（Scrape Now 关） Save / Cancel
Scrape Now 开 Execute / Discard

Execute 结束后，设置恢复默认：On Scheduled 开、Scrape Now 关、12:00 PM、上述六个默认品牌。

自动抓取使用独立通道（每平台最多 6 品牌），不占用用户执行池（最多 10）。

8.4 语言

选择 效果
English 界面为英文
中文 界面为简体中文（与本文术语一致）

8.5 Worker 设置（WhatsApp / Telegram）

展开卡片可配置人工延迟、建群默认、邀请链接节流、设管理员延迟、退出/删除开关。数值在 入队 Job Queue 任务时生效（写入任务载荷）。

9. 数据同步（实时）

9.1 数据库变更 → 已打开的应用

当 IT 或系统在 Supabase 中修改数据（账号、主表群、daily 抓取、会话标记）时：

行为 说明
实时刷新 已打开的应用在数秒至数分钟内更新
无需重装 仅数据变更不需要新安装包

示例：IT 删除测试账号 → 所有用户仪表板上该行消失。

抓取提交 daily + master 后，账号页徽章与群组矩阵从最新数据库刷新（非旧工单缓存）。

9.2 代码 / 界面变更 → 应用更新

需通过新版本（自动更新 + 重启）。见 PROJECT.md §4.4。

变更类型 交付方式
Supabase 数据 实时
新按钮、布局、逻辑 新版 .exe

9.3 本机与云端存储

位置 内容
云端（Supabase） 品牌、账号、群、会话标记
本机（AppData） 每账号 WhatsApp 认证（仅在本机扫码的 PC）、自动抓取偏好、语言、Worker 设置

WhatsApp 多 PC： 会话不能跨 PC 迁移。交接 → 旧 PC 清除会话（可选）→ 新操作员在本机 同步 并扫码。

Telegram 多 PC： 会话字符串在云端 — 会话在线时其他 PC 可 同步 / 抓取。交接 → 必须 清除会话，由新操作员在本机扫码。

10. 推荐日常工作流

10.1 新营销账号上线（测试数据清理后）

# 步骤
1 仪表板 登录
2 打开目标品牌（或 添加卡片）
3 + 添加 → 选 WA/TG → 名称 + 电话 → 保存
4 ↻ 同步 → 在营销手机上扫码
5 若提示 → 抓取
6 查看账号页徽章（Junk / 缺群 / 非管理员）
7 用 Operations Job Queue SETUP 修复 → 任务后再抓取
8 对每个账号重复

12. 常见问题

应用更新需要重新安装吗？
不需要。收到更新提示后重启即可（IT 已发布到 GitHub 时）。

在 Supabase 删除数据会删掉安装程序吗？
不会。仅影响仪表板数据。

会话显示在线，但抓取仍要求登录？
本机可能已失去设备会话 — 点击 同步 重新检查。

群组显示 12/21 是什么意思？
设备检测到 12 个群；21 为该平台的品牌标准群数（WA 与 TG 分开计）。

一台 PC 可以挂很多 WhatsApp 账号吗？
可以，支持大量账号，但每个账号需单独扫码。用户执行并发每平台最多 10；自动抓取每平台最多 6 个品牌。

手机上已修复，缺口还在？
执行 同步 → 抓取，让最新设备数据进入数据库，再查看账号页徽章。

「工单」标签去哪了？
已移除。问题显示在 账号 页；通过 Operations → Job Queue 修复。

还有「群数不一致」工单类型吗？
没有。仅五种：Junk、缺群、非管理员、群 ID 重复、群名重复。

仪表板登录失败？
联系 IT — 需在 users 表中开通账号。

Telegram 二维码或登录报错？
联系 IT — 检查 Telegram API 配置与数据库迁移 023。

卡片视图和表格视图有何区别？
数据相同；卡片按品牌分组，表格为扁平列表。

从列表移除此卡片会删除品牌吗？
会 — 确认后从数据库删除品牌及相关数据。

二维码报错「still starting from previous attempt」？
本机 WhatsApp 会话卡住 — 等待数秒，或对在线会话列使用 清除会话 (X) 后重新同步。

其他同事能否同步我登录的账号？
WhatsApp 不行 — 授权在本机。需 清除会话 后由对方在本机扫码。
Telegram 在会话在线时其他 PC 可用（会话在云端）。交接请 清除会话，由对方在本机扫码。

在哪里改界面语言？
设置 → 语言 → English 或 中文。

在哪里配置自动抓取？
设置 → 账号自动抓取（On Scheduled / Scrape Now）— 不是按分钟间隔的自动同步。
