What is this app?

Desktop app to monitor many WhatsApp and Telegram accounts per brand.

  • See session Active or Logout
  • See gap counts: Junk, Missing, Not admin
  • Run Job Queue: Join missing, Create group, Set admin, Leave group
  • Open stock chips and Group matrix from the Account brand header

Quick start

  1. Install from Team Develop, open the app, log in with username and password
  2. Open Group Monitoring > Account
  3. On accounts with Session Logout, click Sync and scan QR on the marketing phone
  4. When the app asks, choose Scrape now (or Later if you will scrape later)

App login is not WA/TG login. WA/TG login is only through Sync.

Sync and Scrape now

Sync checks the platform session.

  • Session Logout: scan QR (or phone login), then you may get Scrape now / Later
  • Session Active: light session check. Full group numbers update when you choose Scrape now

Scrape now reads all groups from the phone and writes them to the database. Last update shows progress. Do not close the app. Cancel scrape = nothing saved.

After Job Queue changes groups on the phone, run Sync then Scrape now so On device / Junk / Missing / Not admin update.

Operations - Job Queue

Operations = Job Queue only. Choose Platform in the slicer. Brand, task, and account are in the Add bar / SETUP.

Task types (exact labels)

TaskWhat it does
Join missingJoin master groups not yet on the account (invite from master)
Create groupCreate groups on the phone. Role Master. Brand photo required in SETUP. Set photo usually queues automatically after create
Set adminOWNER/ADMIN promotes Account to promote on eligible groups
Leave groupLeave selected groups. If Delete is on in worker Leave & delete, delete chat queues automatically after leave

Status: Queued, Running, Completed, Failed, Cancelled, Paused.
Row controls: VIEW, RUN, PAUSE, CANCEL. SETUP submit = Queue.

Do not Sync the same account while its job is Running.
Up to 10 concurrent execute slots per platform (shared by Sync, Scrape, and jobs).
Large join / leave / set admin / set photo lists split by Settings Max per run (default 30 groups per job row). Same account runs those rows in order.
Create group max default is 25 groups per Master run (separate from the 30 split).

PAUSE / CANCEL / RUN

ButtonWhat happens
PAUSEStops the job. Progress is kept. RUN continues.
CANCELStatus Cancelled. Row stays. RUN can put it back in queue. Delete the row only to remove it.
RUNStarts or resumes Queued / Failed / Cancelled / paused work.

No fixed max retry count. Read VIEW Remark first. If invite expired, get a new link and queue a new Join missing. Do not spam RUN.

Join missing

  1. From Operations, or from Missing list > Join missing
  2. SETUP: drop CSV/XLSX, or open Select from master list and tick groups
  3. Queue
  4. If Failed: VIEW (No / Group / Status / Remark), fix cause if needed, Run
  5. Account: Sync then Scrape now

Create group

When: Need new Ready stock, or To prep > 1 on the brand header.

Account: Role Master. Limits: max about 25 groups per run; one create run per Master per day (used Masters show as used today).

From To prep, pick the Master account inside SETUP.

SETUP cards:

  1. Group batch
    • Group name (required)
    • Total to create (required)
    • Number each group name (switch) + Start from
  2. Group permissions (defaults from Settings; change only for this job)
    • WhatsApp: Admins send only, Admins add only, Admins edit info
    • Telegram: Hide history for members
  3. Upload Photo / Preview Photo (required). Upload or Change before Queue. Without a photo, Queue stays off.
  1. Queue and wait for Completed
  2. Set photo usually queues automatically after create (Remark may say set photo queues automatically)
  3. VIEW shows created groups (name, id, invite link) and Queue Set Photo if you need to retry
  4. Account: Sync then Scrape now

Set admin

  1. OWNER/ADMIN = account already admin in the groups
  2. Account to promote = target
  3. SETUP lists only eligible groups (owner is admin, target joined, not admin yet)
  4. Queue, then Sync + Scrape now on the target account

Leave group

When: Junk or other groups to leave, or Junk list > Leave.

Leave must be enabled under Settings > WhatsApp worker or Telegram worker > Leave & delete.

  1. Pick one account + task Leave group
  2. SETUP tabs:
    • On device - all groups from latest daily scrape
    • Not in master - junk. Junk > Leave opens this tab
  3. Tick groups, Queue
  4. Job leaves the groups. If Delete is enabled in Leave & delete, delete chat queues automatically for groups that Left
  5. Delete here clears/deletes chat on this account. It does not dissolve the group for everyone
  6. VIEW Queue delete (left groups) is mainly to retry if auto-delete failed or did not run
  7. Account: Sync then Scrape now

Note: some Setup window titles may still say "exit & delete" in the title text, but the task tab label is Leave group.

Group matrix

Read-only. Open from the Account brand header group count badge.

Bookmarks: Full Group, Full Admin. Filters and Excel export available. Updates after scrape.

Automatic account scrape

  • Default idle: On Scheduled On, Scrape Now Off, daily time 12:00 PM, brands FWSG / JMMY / M24SG / SBMY / STMY / WBSG (max 6 per platform)
  • Scrape Now Off: buttons Save / Cancel
  • Scrape Now On: buttons Execute / Discard. Brands start unchecked (0/6). Status shows standby until Execute
  • After Execute finishes, settings restore to defaults
  • App must be open at the scheduled time. No catch-up if the app was closed
  • While On Scheduled is running, Scrape Now stays blocked

Common issues

Problems R&M hits most often. If your message is not listed, read VIEW Remark / the alert text, then Contact Team Develop.

What you seeWhat to do
Session Logout, or alert: not logged in / session no longer valid / WhatsApp session timed out… Linked Devices Sync (↻) → scan QR or phone linking (WhatsApp → Linked Devices). If QR never appears: Clear Session (X on Session when Active) → Sync → QR
Navigating frame was detached Clear Session → Sync → QR → Session Active → then VIEW RUN. Do not RUN first
Remark Not Aligned (Junk / Missing / Not admin > 0) Open the gap list → Join missing / Set admin / Leave → Queue. Then Sync → Scrape now
Scrape running (Reading groups…, progress, Cancel scrape) Normal. Keep the app open. Do not Sync or start a job on the same account until it finishes
Job finished but Account numbers / matrix still wrong Sync → Scrape now on that account
Invite expired / rejected (Join missing Failed) Scrape an admin that owns the group → get a fresh invite → new Join missing. Do not spam RUN
Leave is disabled in worker settings Settings → WhatsApp/Telegram worker → Leave & delete → enable Leave → queue again
Create group Queue disabled / need Master Account Role = Master. SETUP needs Group name, Total to create, and Upload Photo
Execute slots busy / account already has a task running Wait. Max 10 accounts per platform; one Sync/scrape/job per account
Job Failed / WhatsApp store flake — retry VIEW → read Remark → RUN once. If the next error is frame detached → Clear Session path above
Scheduled auto scrape did not run App must be open at the schedule time, or Settings → Scrape Now → Execute

Contact Team Develop
