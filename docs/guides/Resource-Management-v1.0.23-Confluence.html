1. Ringkasan

Aplikasi desktop untuk memantau dan mengoperasikan banyak akun WhatsApp dan Telegram per brand marketing. Semua data bisnis (akun, grup, master, ticket, session) disimpan di Supabase. Login platform (WA/TG) berjalan di Electron main process dengan session lokal per PC.

Pengguna: tim internal perusahaan (bukan produk publik).

Highlight v1.0.23:

  • Scrape WA mengambil invite link dari device → tulis daily → rebuild master
  • Stabilitas Puppeteer (protocolTimeout, concurrency metadata, retry)
  • Job Queue: VIEW detail per task + export Excel
  • Validator data nyata (validate:real-operations-data)

5.2 Sync & Run Scraper

  • Sync (↻): probe session device → update hitungan grup/admin → prompt Scraper Now / Later
  • Run Scraper: scrape penuh device → tulis daily → rebuild master → reconcile ticket → refresh UI realtime
  • Later: tutup modal tanpa scrape
  • Cancel scrape: stop total + lepas Chrome

Skala: hingga ~3000 grup per akun (WA store cap + timeout terukur).

5.3 Login Platform

PlatformMetodePenyimpanan session
WhatsAppQR / phone linkingFolder lokal wa-sessions/session-{UUID} per PC
TelegramQRSidecar + session string di DB

Clear Session (X): purge disk WA + invalidate DB → login ulang bersih.

5.4 Modal Group Links

  • Groups on account: semua baris daily akun (No, nama, ID, member, admin, is admin, invite link)
  • Admin vs master: baris master brand + status join/admin dari daily
  • Export Excel: RM-[nama akun]-YYYYMMDD.xlsx

5.5 Manajemen Akun

  • Tambah / edit akun (label, phone, location MY/KH)
  • Hapus akun → CASCADE DB + rebuild master
  • Multi-slot per brand (100+ akun WA/TG)

10. Pipeline Data Scrape (Kontrak Produksi)

Device (WA Electron / TG sidecar)
  → runAccountScraper
  → DELETE daily (account_id)
  → INSERT group_scrape_daily
      (group_id, group_name, invite_link, counts, is_admin)
  → RPC rm_rebuild_brand_groups_master
      (hanya invite_link valid masuk master)
  → reconcileTickets + refresh grid/ticket/reporting

WA scrape v1.0.23:

  • Fase 1: metadata grup paralel (concurrency 4)
  • Fase 2: invite link serial per grup admin (getInviteCode)
  • Puppeteer protocolTimeout 10 menit + retry ProtocolError

TG scrape: invite via username atau ExportChatInviteRequest (sidecar).

13. Distribusi & Rilis

13.2 Tim Operator (pakai)
