1. 概述

1.1 本应用做什么？

资源管理帮助团队完成以下工作：

能力 说明
多账号登记 按品牌（如 SBMY）登记多个 WhatsApp 与 Telegram 账号
会话健康 检查账号在手机/本机是否仍在线（会话）
群组对齐 对比设备上的群与品牌标准群清单（主表）
抓取 从设备完整读取群组并写入数据库
工单 / 问题 查看需修复项（缺标准群、非管理员、重复、设备多余群等）
导出 将筛选结果导出为 Excel，供现场作业使用

1.2 两种「登录」

请勿混淆 — 用途完全不同。

类型 用途 操作方式
仪表板登录 进入应用 用户名 + 密码（由 IT 提供，对应 users 表）
平台登录 将 WA/TG 关联到营销账号 点击 同步 (↻) → 二维码或手机号登录弹窗

仪表板密码不是 Telegram 或 WhatsApp 的密码。

1.3 什么**不会**生成工单？

会话列中的登录/登出变化不会产生工单。工单仅针对相对品牌标准的群组与管理员问题。

品牌 品牌名 本卡片内各行相同
状态 在线 = 会话有效；已登出 = 无效 绿 / 红指示

4.4 行内控件

控件 功能
↻（同步） 主流程：平台登录或检查本机会话并更新计数

提示文字：同步账号。

4.5 **同步 (↻)** 流程 — 必读

行为取决于 会话 列取值。

会话 = **无效**

步骤 说明
1 点击 ↻
2 打开平台登录弹窗（默认二维码，或手机号登录）
3 在营销手机上扫码（WA：已关联的设备；TG：设置 → 设备 → 链接桌面设备）
4 成功后：会话保存，群组数字更新
5 可能提示 抓取 — 将完整群列表写入数据库

会话 = **有效**

步骤 说明
1 点击 ↻
2 应用检查本 PC 上 WA/TG 是否仍活跃
3 正常：更新 群组 / 管理员 数字
4 失败：提示重新登录

说明：

  • 平台登录仅在桌面客户端内完成（不能仅靠浏览器）。
  • 若约 10 秒内未显示二维码：关闭窗口，等待数秒后再次 同步。
  • Telegram 群很多时同步超过 3 分钟：重试或重启应用。

4.6 **抓取** 列 — **运行** 按钮

条件 显示 操作
会话无效 请先点击同步 (↻) 登录 先同步
已对齐 仅显示 最后更新 时间 通常无需运行
未对齐 运行 + 时间戳 点击 运行 → 从手机读取全部群 → 写入 DB → 工单刷新
运行中 读取群组中… / 进度 等待（群多时可需数分钟）
术语 含义
运行 / 运行抓取 完整抓取 — 全部群写入数据库
同步 检查会话 + 汇总计数 — 不一定是完整抓取

登录成功后可能提示：登录成功，设备群组与管理员数已更新。是否立即抓取并写入数据库？ → 选 抓取 或 稍后。

5. 「工单」标签 — 问题与修复

5.1 何时出现工单？

账号完成抓取/同步后，系统比对设备群（每日快照）与品牌主表。存在差异则自动生成工单。

工单卡片数字与账号页的群组/管理员列使用 同一套引擎 — 不是数据库原始行数。

5.2 工单类型（筛选：**全部工单类型**）

类型（界面） 简要含义 常见现场操作
缺标准群 品牌主表有、本账号无 入群（用导出邀请链接）
非管理员 已在群但非 Admin 申请管理员
群数不一致 设备群数 ≠ 品牌标准 核对并对齐
群 ID 重复 相同 ID、名称冲突 核对主表数据
群名重复 同名不同 ID（主表） 核对主表数据
设备多余群 手机有、主表无 在手机上清理/退群

会话登录/登出不会生成工单。

5.3 工单工具栏

工具 功能
搜索 搜索账号 / 群组…
品牌 / 平台 / 类型筛选 缩小工单列表

书签：已完成 任务状态为「完成」的工单

7. 数据同步（实时）

7.1 数据库变更 → 已打开的应用

当 IT 或系统在 Supabase 中修改数据（账号、工单、主表群、会话标记）时：

行为 说明
实时刷新 已打开的应用在数秒至数分钟内更新
无需重装 仅数据变更不需要新安装包

示例：IT 删除测试账号 → 所有用户仪表板上该行消失。

7.2 代码 / 界面变更 → 应用更新

需通过新版本（自动更新 + 重启）。见 PROJECT.md §4.4。

变更类型 交付方式
Supabase 数据 实时
新按钮、布局、逻辑 新版 .exe

7.3 本机与云端存储

位置 内容
云端（Supabase） 品牌、账号、群、工单、会话标记
本机（AppData） 每账号 WhatsApp 认证（仅在本机扫码的 PC）、自动同步偏好、语言

WhatsApp 多 PC： 会话不能跨 PC 迁移。交接 → 旧 PC 清除会话（可选）→ 新操作员在本机 同步 并扫码。

Telegram 多 PC： 会话字符串在云端 — 会话有效时其他 PC 可 同步/运行抓取。交接 → 必须 清除会话，由新操作员在本机扫码。

品牌 运营单元（如 SBMY），含各 WA/TG 标准群主表
账号 / 槽位 品牌下的一行 WA 或 TG 账号
主表 / 标准 品牌标准群清单（groups_master）
每日快照 当日从设备读取的群列表
已对齐 设备群数与该品牌该平台标准一致
会话有效 数据库中有活跃会话（当日可能仍需设备检查）
同步 ↻ 按钮 — 登录或检查本机设备
运行抓取 从手机完整读取群 → 数据库
工单 / 问题 群组数据修复任务
书签 工单筛选：进行中 / 已完成
切片栏 卡片/表上方的筛选与工具条
群组监控 账号与工单主模块
后端运营 侧栏显示的产品系列名称

10. 常见问题

应用更新需要重新安装吗？
不需要。收到更新提示后重启即可（IT 已发布到 GitHub 时）。

在 Supabase 删除数据会删掉安装程序吗？
不会。仅影响仪表板数据。

会话显示有效，但运行抓取仍要求登录？
本机可能已失去设备会话 — 点击 同步 重新检查。

群组显示 12/21 是什么意思？
设备检测到 12 个群；21 为该平台的品牌标准群数（WA 与 TG 分开计）。

一台 PC 可以挂很多 WhatsApp 账号吗？
可以，支持大量账号，但每个账号需单独扫码；Chrome 并发进程约限制为 4 个左右。

手机上已修复，工单还在？
点击 运行抓取 或 同步，让最新设备数据进入数据库。

仪表板登录失败？
联系 IT — 需在 users 表中开通账号。

Telegram 二维码或登录报错？
联系 IT — 检查 Telegram API 配置与数据库迁移 023。

卡片视图和表格视图有何区别？
数据相同；卡片按品牌分组，表格为扁平列表。

从列表移除此卡片会删除品牌吗？
会 — 确认后从数据库删除品牌及相关数据。

二维码报错「still starting from previous attempt」？
本机 WhatsApp 会话卡住 — 等待数秒，或对有效会话列使用 清除会话 (X) 后重新同步。

其他同事能否同步我登录的账号？
WhatsApp 不行 — 授权在本机。需 清除会话 后由对方在本机扫码。
Telegram 在会话有效时其他 PC 可用（会话在云端）。交接请 清除会话，由对方在本机扫码。

在哪里改界面语言？
管理 → 偏好设置 → 语言 → English 或 中文。
