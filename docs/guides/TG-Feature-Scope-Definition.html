TG Feature Scope Definition

Document information
ScopeTelegram accounts, all brands (MYR & SGD)
ToolsGM Apps (Group Monitoring)

Full scope of Telegram features built in GM Apps, mirroring the existing WhatsApp implementation. Each feature below is broken down by what it does and how it works.

1. Sync

Checks the real connection between the account and Telegram before any other action runs.

  • If the session is Logout, Sync opens the login screen (phone number and code, or QR)
  • If the session is Active, Sync verifies the session through the Python sidecar before allowing Scrape to continue
  • Runs through the same execute slot pool as WhatsApp Sync, one account can only run one Sync/Scrape/Job at a time

2. Scrape

Reads the full group list from the account and saves it.

  • Runs through telegramScrape.ts in the main process, paired with the Python sidecar for the actual Telegram-side read
  • Result feeds into the same Aligned, Junk, and Review calculation used by WhatsApp, no separate logic per platform
  • Capped at 6000 groups per account, same cap as WhatsApp, with a truncation warning shown in the UI if exceeded

3. Stock Group

Classifies every scraped group into Ready, Recycle, or Review, shown as chips on the brand header.

  • Uses the same shared classification logic as WhatsApp (classifyGroupStock.ts), no Telegram-specific rules
  • A group that does not match any SOP naming pattern for the brand automatically falls into Review

4. Job Queue

All job types below share the same Job Queue, Worker Settings, and batch split (30 groups per job) as WhatsApp.

4.1 Join Missing

Joins groups that the account should be in but has not joined yet, using the invite link from the group master list. Includes automatic retry on FloodWait (Telegram's rate limit), with auto-sleep up to 7200 seconds.

4.2 Create Group + Set Photo

Creates a new group and sets its photo right after creation. Group naming and photo follow the same SETUP form as WhatsApp (group name, total to create, upload photo required before Queue is enabled).

4.3 Set Admin

Promotes an account to admin in a group, with 11 individually configurable admin rights, wider than WhatsApp's 3:

#Right
1Change group info
2Post messages
3Edit messages
4Delete messages
5Ban users
6Invite users
7Pin messages
8Add new admins
9Manage voice/video calls
10Stay anonymous
11Delete stories

4.4 Leave Group

Leaves selected groups, picked from the On device or Not in master (Junk) tab in SETUP, same tab structure as WhatsApp.

4.5 Delete Chat

Removes the group from the account after leaving. Requires the account to already hold admin rights in that group; Telegram does not allow a non-admin account to delete a group. Automatically queued right after Leave Group completes, following the same Leave & Delete worker setting as WhatsApp.
