1. Overview & Arsitektur / Architecture

Resource Management (GM Apps) adalah aplikasi desktop Electron untuk mengelola ratusan akun WhatsApp & Telegram per brand. Data grup hidup di Supabase. Device action (login, scrape, join, create, admin, leave) jalan di mesin lokal — bukan di server.

Resource Management (GM Apps) is an Electron desktop app that manages hundreds of WhatsApp & Telegram accounts per brand. Group data lives in Supabase. Device actions (login, scrape, join, create, admin, leave) run on the local machine — not on a remote server.

4. Core — Sync

Sync di kolom Session / tombol Sync = cek session device. Bukan hitung Groups Y/X. Session tersimpan di disk/DB = Valid — busy/timeout probe bukan Logout.

Sync on the Session column / Sync button checks the device session. It does not recount Groups Y/X. A session on disk/DB is Valid — probe busy/timeout is not Logout.

10. Known Patterns & Gotchas

Pola yang berulang

Recurring patterns

  • Satu pintu cycle untuk auto scrape scheduled + now — runAutoScrapeCycle
  • Auto-chain job create→photo, leave(exit)→delete — jangan cari step kedua di UI Setup
  • Lane terpisah user scrape (scraper:run) vs auto (scraper:run-auto)
  • Realtime setelah daily write → patch grid + debounce reload Operations / matrix 500ms
  • CTA → JobQueueSetupHost → SetupModal → enqueue dipakai Account dan Operations
  • File Reporting* = Group matrix modal, bukan tab Reporting lama.
  • Files named Reporting* = Group matrix modal, not the old Reporting tab.
  • Jangan cari reconcileTickets.ts / tab Ticket DB — sudah mati.
  • Don’t look for reconcileTickets.ts / Ticket DB tab — gone.
  • Time Scrape di UI auto scrape pakai runStatus.updatedAt, bukan snapshot jam jadwal stale.
  • Auto-scrape Time Scrape uses runStatus.updatedAt, not a stale schedule-hour snapshot.
  • Jangan buka dua Puppeteer untuk sessionId yang sama; jangan cabut lock di forceRelease sembarangan.
  • Never open two Puppeteer clients for the same sessionId; don’t casually drop locks in forceRelease.
  • exit_delete_group legacy vs leave+delete chain — cek payload exitDeletePhase dulu.
  • exit_delete_group legacy vs leave+delete chain — check exitDeletePhase on the payload first.
  • Issue/KPI hanya dari grup/admin — login/logout session bukan Issue.
  • Issues/KPIs are group/admin only — session login/logout is not an Issue.
