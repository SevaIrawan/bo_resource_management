What is this app?

A desktop app to watch and manage many WhatsApp and Telegram accounts, grouped by brand.

  • See which accounts are logged in and which are logged out
  • See gap counts: Junk, Missing, Not admin
  • Run tasks from the Job Queue: Join missing, Create group, Set admin, Leave group
  • Open stock numbers and Group matrix from the brand header

Quick start

  1. Open the app and log in with your username and password
  2. Go to Group Monitoring > Account
  3. For any account showing Logout, click Sync and scan the QR code on the marketing phone
  4. When asked, choose Scrape now (or Later if you want to scrape at a different time)

Logging into the app is not the same as logging into WhatsApp or Telegram. WA/TG login only happens through Sync.

Gap lists and Job Queue shortcuts

How it actually works

Click a gap number (Junk / Missing / Not admin), the group list opens, then press Join missing, Set admin, or Leave. This opens SETUP. Fill it in and press Queue.

You can also open SETUP from the Operations Add bar without going through a gap list.

VIEW, RUN, PAUSE, and CANCEL control tasks already sitting in the queue. They are not shortcuts from the Account tab.

Junk countLeaveLeave group (SETUP opens on the Not in master tab)

Sync and Scrape now

Sync checks the real connection to the phone. Scrape now reads the full group list from the phone and saves it.

  1. If Session shows Logout: Sync opens the QR or phone linking screen right away
  2. If Session shows Active: Sync first checks the phone (you will see Checking Session, up to 20 seconds), then asks if you want to Scrape now or Later
Why the check takes a moment

This check makes sure the account is really connected before doing anything else. It also stops two Chrome windows from opening for the same account at the same time, which used to cause a blank white window. Let it finish, do not close the app or click Sync again while it is checking.

One account, one task at a time

An account can only do one thing at a time: Sync, Scrape, or a Job Queue task. This is on purpose, running two things on the same account at once causes errors.

  • If a Job Queue task is running on an account and you press Sync, you will see a busy message. Wait for the task to finish, then try again
  • If Sync or Scrape is running on an account, any Job Queue task waiting for that same account will simply wait its turn. It does not need to be started again by hand, it starts on its own once Sync or Scrape is done

Up to 10 accounts per platform can be active at the same time. If you hit that limit, wait for one to finish.

Stock on brand header

Stock numbers show on the Account brand header. They update automatically after a scrape, and can also update on a schedule from Settings.

Operations - Job Queue

Go to Operations to see and manage every task: SETUP to create a new one, VIEW to check details, RUN, PAUSE, CANCEL for tasks already queued.

Create group

SETUP cards:

  1. Group batch
    • Group name (required)
    • Total to create (required)
    • Number each group name (toggle) and Start from
  2. Group permissions (comes from Settings by default, you can change it just for this task)
    • WhatsApp: Admins send only, Admins add only, Admins edit info
    • Telegram: Hide history for members
  3. Upload Photo / Preview Photo (required). Upload or change it before pressing Queue. Without a photo, Queue stays off
  1. Press Queue and wait for it to show Completed
  2. Set photo usually queues by itself right after the group is created
  3. VIEW shows the groups created (name, id, invite link) and a Queue Set Photo button if you need to retry
  4. Go back to Account and run Sync then Scrape now

Set admin

  1. OWNER/ADMIN is the account that is already admin in the groups
  2. Account to promote is the account you want to make admin
  3. SETUP only lists groups where this actually applies: owner is admin, target has joined, target is not admin yet
  4. Press Queue, then Sync and Scrape now on the target account

Leave group

When to use it: for Junk groups, or any group you want to leave.

Leave has to be turned on first, under Settings > WhatsApp worker or Telegram worker > Leave & delete.

  1. Pick one account and the Leave group task
  2. SETUP tabs:
    • On device: every group from the latest scrape
    • Not in master: junk groups. Clicking Junk > Leave opens this tab directly
  3. Tick the groups you want, press Queue
  4. The task leaves the groups. Right after that, delete queues on its own for every group that was left successfully, this is the normal behavior
  5. Delete here means: this account leaves the group and its chat history is also cleared on this account. It does not delete the group for everyone else in it
  6. VIEW has a Queue delete (left groups) button, use it only if the automatic delete did not run or failed
  7. Go back to Account and run Sync then Scrape now
Note

Some SETUP window titles may still say "exit and delete", but the task tab is simply called Leave group, and it works the same way described above.

Group matrix

Read only view. Open it from the group count badge on the Account brand header.

Bookmarks: Full Group, Full Admin. You can filter and export to Excel. It updates after a scrape.

Automatic account scrape

  • Default: On Scheduled is on, Scrape Now is off, runs daily at 12:00 PM, for brands FWSG / JMMY / M24SG / SBMY / STMY / WBSG, up to 6 per platform
  • Scrape Now off: buttons are Save / Cancel
  • Scrape Now on: buttons are Execute / Discard. Brands start unchecked, status shows standby until you press Execute
  • After Execute finishes, the settings go back to default
  • The app has to be open at the scheduled time. It will not catch up later if it was closed
  • While the scheduled run is happening, Scrape Now stays blocked

Common issues

The problems R&M runs into most often. If yours is not listed here, check the VIEW Remark or the alert text first, then contact Team Develop.

Login and session
Session shows Logout, or you see a message about the session no longer being valid
  1. Press Sync and scan the QR, or use phone linking (WhatsApp > Linked Devices)
  2. If the QR never shows up, click Clear Session (the X next to Session while Active), then Sync again
Error message: "Navigating frame was detached"

Can happen during Sync or while a Scrape is running.

  1. Click Clear Session on that account
  2. Sync again and log in (scan the QR or use phone linking)
Sync, scrape, and busy accounts
An account is busy, or a task will not start on an account with another task already running
  1. This is expected. One account can only do one thing at a time
  2. Wait for the current Sync, Scrape, or Job task to finish, it will continue on its own
  3. Up to 10 accounts per platform can run at once
Scrape is running (you see "Reading groups...", a progress bar, or Cancel scrape)
  1. This is normal, keep the app open
  2. Do not Sync or start a task on the same account until it finishes
A task finished but the numbers on Account or the matrix still look wrong
  1. Go to Account, press Sync, then Scrape now
Job queue
Join missing failed because the invite link expired or was rejected
  1. Scrape an admin account that owns the group to get a fresh invite link
  2. Start a new Join missing task with the fresh link
  3. Do not press RUN repeatedly on the same failed task
Message: "Leave is disabled in worker settings"
  1. Go to Settings > WhatsApp worker or Telegram worker > Leave & delete
  2. Turn Leave on
  3. Queue the task again
Create group Queue button stays disabled, or it asks for Master
  1. Account Role has to be Master
  2. SETUP needs a Group name, Total to create, and a photo uploaded
Task shows Failed, or a message about a WhatsApp store error
  1. Open VIEW and read the Remark
  2. Press RUN once to retry
  3. If the next error is "frame detached", follow the Clear Session steps above instead
Settings
Scheduled auto scrape did not run
  1. The app has to be open at the scheduled time
  2. Or go to Settings > Automatic account scrape > turn on Scrape Now > Execute

Contact Team Develop

Only reach out after trying the steps above. When you do, include the app version (1.0.33), brand, account, platform, what you did step by step, screenshots, and the Remark text.
