2. Build and Packaging

ToolPurposeSetup notes
PyInstaller (onefile)Bundles the sidecar into a single executableRuns inside a dedicated build venv, output is rm-telegram-sidecar.exe on Windows, rm-telegram-sidecar on macOS/Linux
npm run build:sidecarTriggers the full sidecar build (scripts/build-telegram-sidecar.mjs)Auto-detects the host Python (python3/python on macOS/Linux, python/py -3 on Windows), or uses the PYTHON environment variable if set

3. Installer Bundling

The built sidecar binary is copied into resources/sidecar/ and packaged inside the installer alongside the main Electron app, same installer for Windows, macOS, and Linux. No separate installation step is needed on the user's side.

4. Overall Readiness

All dependencies are pinned with minimum versions, the build pipeline is scripted end to end (build:sidecar), and the sidecar is already bundled into the shipped installer. Ready for Telegram integration, no additional tooling required before implementation.
